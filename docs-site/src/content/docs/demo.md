## Scenario

A store associate records recurring shelf-label mismatches during opening checks. The current process uses chat messages and a spreadsheet, so ownership and closure are hard to inspect.

Submit an idea named **Shelf Signal**:

- Problem: capture label mismatches, route them to the department owner, and show open items by store area.
- Repository: `shelf-signal`.
- Audience: the synthetic store-operations Entra group.

Open the generated repository in the builder's preferred Copilot surface. Run the `idea-framer`, `solution-architect`, `app-builder`, and `test-and-review` agents in order. Keep the approved scope small: create, assign, resolve, and list issues.

Push the reviewed change to `main`. Show the OIDC login, test and scan gates, image digest, namespace deployment, and authenticated application.

Close with the system evidence: repository ownership, exact deployment subject, namespace quota, default-deny policy, audit event, and explicit runtime deletion.
